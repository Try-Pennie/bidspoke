Failed runs link: the settled design (#2102)

Settled with Dan in two rendered design rounds on 2026-10-15, one question a round: round 1 option 2, "A failed run count that links", and round 2 option 3, "The list's own title". Built in apps/web/src/components/dashboard/IncidentsSection.tsx (the card), apps/web/src/components/canvas/ExecutionListPanel.tsx (the run list), apps/web/src/lib/incidents.ts (their words), and the worker route GET /api/incidents/:id/failed-runs with apps/worker/src/lib/incident-failed-runs.ts.

Decision 1: a failure rate row says how many failed runs, and the count is the link (round 1)

On the Incidents card, only a failure rate row's pages column reads "2 Slack pages, 12 failed runs", with "12 failed runs" a link in the product's blue, underlined. The count says how many there are before anyone clicks. It is the failed runs matching that incident, inside its time span, among the runs still kept. When none of the span is still kept there is nothing to open, so the row shows no count and no link. A kept span with no matching run shows "0 failed runs" as plain text. A count that could not be read is left out rather than shown as 0, and the row is otherwise intact. Making the subject the link, and making the whole row clickable with an arrow, were rendered and set aside.

Decision 2: the link opens the workflow page with its run list narrowed, under the list's own title (round 2)

The link opens /workflows/<workflow id>?incident=<incident id>. While narrowed, the run list's header replaces the EXECUTIONS label: a "‹ All runs" link back to every run, the title "12 failed runs in this incident", and a grey line naming the match and the span in ET ("ACRO_GATEWAY", Today 2:34 PM to 4:06 PM ET; an end on another day carries its day; an incident with no recorded end reads since its start). The outcome tabs are hidden: the title keeps the narrowing on screen, and a tab row would contradict it. A banner above the tabs, and a removable filter tag under them, were rendered and set aside.

Decision 3: one more grey line, only when it applies

When the incident started before the runs still kept, the header carries "Runs before Oct 8 are no longer kept." It appears only then, so it never repeats a fact that is not true of the incident on screen.

Decision 4: one rule, one read

The runs are the ones failure rate's own rule matches (the shared predicate the alert itself uses, never a copy), windowed on completed_at between the incident's start and end, clipped to the 7 days runs are kept. The card's count and the list's title come from the same read as the list, so the number on the card, the title and the rows cannot disagree. The narrowing lives in the URL so the link can be shared and Back works; the worker resolves the incident by id inside the caller's organization, and takes nothing else about it from the URL.

States the drawing does not show

The narrowed list shows a loading skeleton while it reads, and a failed read as an error with a Retry, never as an empty list. A narrowed list of 0 runs says so in its title alone.

Where the build departs from the drawing

The drawing narrowed the card's columns so the pages column could take the extra words, which wraps the time range and the pages text onto two lines. The build keeps the card's own widths for time and signal (170 and 190px), trims duration from 210 to 200px, widens the pages column to 170px so "2 Slack pages, 12 failed runs" stays on one line, and lets the subject column give up the width; the card's minimum width before it scrolls sideways grew from 860 to 940px so the subject keeps room. The pages text keeps the built card's own 12px gray 600 rather than the drawing's 13px gray 500.

What is the rendering, not the design

The card is drawn at its laptop width (1008px) and the workflow page at 1100px with the run list at its real 288px, each scaled to fit this page. The canvas beside the list is a drawn slice standing in for the real canvas, the incidents and the twelve runs are invented samples, and the system font stack stands in for the app's Geist. None of these were decided.
